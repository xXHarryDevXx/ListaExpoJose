# Questão 06 - Eleição Estudantil

Aplicação desenvolvida em React Native (Expo) que regista os votos para três candidatos numa eleição de representantes estudantis. O sistema apresenta o total de votos por candidato, o total geral e indica em tempo real o candidato mais votado, alertando também caso exista um empate na liderança.

## 🚀 Como executar localmente

1. Abra o terminal nesta pasta (`questao06`).
2. Instale as dependências: `npm install`
3. Inicie o servidor: `npx expo start`
4. Escaneie o QR Code com a aplicação Expo Go.
