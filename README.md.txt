# Lista de Exercícios - React Native (Expo)

Repositório destinado à resolução da lista de aplicativos mobile desenvolvidos com React Native e Expo.

## 📂 Estrutura do Repositório

- [`/questao01`](./questao01) - Calculadora de Hidratação Diária
- `/questao02` - (Em breve)

## 🚀 Como executar os projetos

1. Acesse a pasta da questão desejada (Ex: `cd questao01`).
2. Instale as dependências com `npm install`.
3. Inicie o servidor do Expo com `npx expo start`.
4. Escaneie o QR Code com o aplicativo **Expo Go** no celular.
