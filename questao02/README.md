# Questão 02 - Sistema Acadêmico (Cálculo de Média)

Aplicativo desenvolvido em React Native (Expo) que recebe o nome e três notas de um estudante, calcula a média aritmética e informa se ele foi aprovado (média ≥ 7,0) ou reprovado, com validação de notas entre 0 e 10.

## 🚀 Como executar localmente

1. Abra o terminal nesta pasta (`questao02`).
2. Instale as dependências: `npm install`
3. Inicie o servidor: `npx expo start`
4. Escaneie o QR Code com o aplicativo Expo Go.
