# Questão 08 - Registo Académico

Aplicação desenvolvida em React Native (Expo) para armazenar e exibir informações de estudantes. O sistema recebe dados de um formulário (nome, matrícula, e-mail e curso) e armazena-os num array de objetos, renderizando cada estudante através de cards usando a função `map()`. A aplicação conta com validação de campos obrigatórios, bloqueio de matrículas duplicadas e funcionalidade para remover os registos individualmente.

## 🚀 Como executar localmente

1. Abra o terminal nesta pasta (`questao08`).
2. Instale as dependências: `npm install`
3. Inicie o servidor: `npx expo start`
4. Escaneie o QR Code com a aplicação Expo Go.
